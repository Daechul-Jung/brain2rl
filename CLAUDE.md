## Project Overview

**Brain2RL** has two parallel research tracks sharing the same environment infrastructure:

| Track | Description |
|-------|-------------|
| **Pure RL** (`research/pure_rl/`) | Iterate on RL algorithms, reward shaping, network architectures — no EEG. Validated ideas transfer to the EEG track. |
| **EEG RL** (`research/`) | Condition REPPO on EEG brain signals. Insights from Pure RL track feed into this track. |

Tasks of interest: `PickCube-v1`, `PushCube-v1`, `StackCube-v1`, `PullCube-v1` — do not change unless told.

### Data
- **EEG data**: `data/alpha_wave_arm_data/alpha-training-task/` — raw `.txt` EEG recordings from 8 subjects, 4 tasks
- **Offline RL data**: `data/offline/` — generated by `scripts/generate_offline_data.py` from a trained REPPO agent

## Research Environment — How to Use

### Pure RL track: Add a new idea

1. Write spec in `research/pure_rl/ideas/NNN_idea_name.md`
2. Implement in `research/pure_rl/agents/your_agent.py`
3. Run: `pytest tests/test_06_pure_rl.py tests/test_07_rewards.py`
4. If successful, consider porting to EEG RL track

### EEG RL track: Add a new brain conditioner

1. Write spec in `research/ideas/NNN_idea_name.md`
2. Implement in `research/brain/your_idea.py` — subclass `BrainConditioner`
3. Pass it: `EEGRePPOAgent(brain=YourIdea(...))`
4. Run: `pytest tests/test_02_brain.py tests/test_03_agent.py tests/test_05_integration.py`

### Test layer rules

**Always run all layers before committing. All must pass.**

```bash
# Run full suite
python3 -m pytest tests/ -q --tb=short

# Individual layers
python3 -m pytest tests/test_01_tokenizer.py -v    # EEG track
python3 -m pytest tests/test_02_brain.py -v        # EEG track
python3 -m pytest tests/test_03_agent.py -v        # EEG track
python3 -m pytest tests/test_04_envs.py -v         # Shared
python3 -m pytest tests/test_05_integration.py -v  # EEG track
python3 -m pytest tests/test_06_pure_rl.py -v      # Pure RL track
python3 -m pytest tests/test_07_rewards.py -v      # Shared
```

ManiSkill tests auto-skip if ManiSkill is not installed — expected, not a failure.

## Key Commands

### Pure RL — Train REPPO on ManiSkill

```bash
# Headless (fast)
python3 research/pure_rl/experiments/train_reppo.py \
    --env PickCube-v1 --num-envs 4 --total-steps 500000

# Single env
python3 research/pure_rl/experiments/train_reppo.py \
    --env PickCube-v1 --total-steps 200000
```

### Pure RL — Collect offline data + Train TD3+BC

```bash
# 1. Collect demonstrations from trained REPPO
python3 scripts/generate_offline_data.py \
    --env PickCube-v1 \
    --checkpoint output/pure_rl/PickCube_<run>/final.pth \
    --n-steps 50000 \
    --out data/offline/PickCube.npz

# 2. Train TD3+BC on offline data
python3 research/pure_rl/experiments/train_td3_bc.py \
    --env PickCube-v1 \
    --data data/offline/PickCube.npz \
    --total-updates 200000
```

### EEG RL — Train EEG-conditioned REPPO

```bash
python3 research/experiments/train_reppo.py \
    --env PickCube-v1 \
    --eeg-csv data/processed/train.csv \
    --total-steps 500000
```

### Simulate trained agents

```bash
# MuJoCo / Gymnasium
python3 scripts/simulate_mujoco.py \
    --env Pendulum-v1 \
    --checkpoint output/pure_rl/run/final.pth \
    --agent reppo --episodes 5

# ManiSkill
python3 scripts/simulate_maniskill.py \
    --env PickCube-v1 \
    --checkpoint output/pure_rl/PickCube_run/final.pth \
    --episodes 5

# Save video instead of GUI
python3 scripts/simulate_maniskill.py \
    --env PickCube-v1 \
    --checkpoint output/pure_rl/PickCube_run/final.pth \
    --video-dir output/videos/PickCube
```

### ROS2 Workspace (OpenArm)

```bash
cd ros2_ws
colcon build --packages-select openarm_description openarm_ros
source install/setup.bash
ros2 launch openarm_ros openarm_gazebo.launch.py
```

## Architecture — Key Abstractions

### EEGTokenizer (`research/eeg/tokenizer.py`)
- Input: `(B, C, T_eeg)` — batch, EEG channels, raw time samples
- Output: `(B, T_rl, token_dim)` — one token per RL timestep
- `T_rl` is passed at forward time

### BrainConditioner (`research/brain/base.py`)
- ABC all EEG-conditioning modules must implement
- `forward(token_seq, t) → {'delta_action': (B, action_dim), 'alpha': (B, 1)}`
- **Swapping ideas**: implement this interface, no other files change

### TransformerDelta (`research/brain/transformer_delta.py`)
- Causal TransformerEncoder on token_seq[0..t] + [ACT] cross-attention → delta + alpha gate
- alpha ∈ [0, 1]: confidence gate suppresses EEG when noisy

### EEGRePPOAgent (`research/agents/eeg_reppo.py`)
- `final_action = tanh(base_action + alpha * delta)`
- During `update()`, raw EEG re-tokenized inside the computation graph → gradients reach tokenizer

### PureRePPOAgent (`research/pure_rl/agents/reppo/agent.py`)
- Thin wrapper around `RePPOAgent` compatible with both Gymnasium (numpy obs) and ManiSkill 3.0 (torch tensor obs)
- `collect() / update() / save() / load()`

### RePPOAgent (`models/rl/agents/reppo.py`)
- Categorical Q-learning (151 atoms, Vmin=-2500, Vmax=2500)
- Actor: entropy + KL regularization (temperature α, Lagrange λ)

### TD3BCAgent (`research/pure_rl/agents/td3bc/agent.py`)
- Offline RL: TD3 Q-learning + behavioral cloning regularization
- `OfflineReplayBuffer.from_file(path)` loads `.npz` datasets

### make_env (`research/envs/registry.py`)
- `make_env(env_id, **kwargs)` — supports Gymnasium/MuJoCo, ManiSkill pick-and-place, OpenArm-v0
- ManiSkill 3.0: returns `torch.Tensor (N, obs_dim)` obs directly
- GPU PhysX constraint: only one ManiSkill env may initialize GPU PhysX per process

## Code Structure Rules

1. **One class per file.** Each `nn.Module` subclass and each agent class lives in its own file.
2. **One purpose per file.** Group by what the file does:
   - `config.py` — hyperparameter dataclass only
   - `networks.py` — `nn.Module` subclasses only
   - `replay_buffer.py` — data storage and sampling only
   - `agent.py` — agent logic that imports from the above
   - `__init__.py` — public exports only, no logic
3. **Packages over monoliths.** When an agent exceeds ~150 lines, split into the above layout under `research/pure_rl/agents/<name>/`.
4. **Research agents live in `research/`.** `models/` holds base classes and shared primitives. `models/rl/agents/td3_bc.py` is a backward-compat shim only.
5. **No training loops inside agent packages.** Training entry points (`train_*.py`) belong in `research/pure_rl/experiments/` or `research/experiments/`.

## Conventions

- **Python 3.10+** (uses `int | None` union syntax)
- All models use `torch.device`; check `torch.cuda.is_available()`
- EEG segments stored as `(N, C, T)` — channel dim is **second**
- Action space always `[-1, 1]` (tanh-squashed)
- Save paths default to `output/<run_name>/` — gitignored
- Never commit: large data files, model checkpoints, `.agents/`
- **No commits without explicit approval**

## EEG Data Format

Raw files: `data/alpha_wave_arm_data/alpha-training-task/s{N}_d{M}_training.txt`
- Tab/space separated; columns: timestamp + EEG channels + label
- See `notebooks/eeg_data_analysis.ipynb` for exploration

Pre-processing via `models/classification/data_utilities.py`:
- `load_sensor_data(csv_path, group_by='sequence_id')` → `(X_raw, y_str, groups, df)`
- `preprocess_multilabel(X_raw, y_str)` → `(X, y_enc, scaler, encoders)`
