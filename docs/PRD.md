# PRD: Brain2RL — EEG-Conditioned and Pure Reinforcement Learning

## Goal

Two parallel research tracks sharing the same environment infrastructure:

| Track | Description |
|-------|-------------|
| **Pure RL** | Iterate on RL algorithms, reward shaping, network architectures without EEG. Validated ideas transfer to the EEG track. |
| **EEG RL** | Condition the RL agent on EEG brain signals (pick, push, pull, stack motor intentions). EEG tokens are produced by a Conv1D tokenizer and processed by a pluggable brain conditioner. |

## Core Features

### Shared Infrastructure

**Environment registry** (`research/envs/registry.py`)
- `make_env(env_id, **kwargs)` factory for: Gymnasium/MuJoCo, ManiSkill3 pick-and-place, OpenArm MuJoCo
- Tasks of interest: `PickCube-v1`, `PushCube-v1`, `StackCube-v1`, `PullCube-v1` — not changed unless explicitly requested
- Both tracks use the same env factory; experiments only differ in the agent type

**Offline dataset** (`scripts/generate_offline_data.py`)
- Collects demonstrations from a trained REPPO agent on ManiSkill pick-and-place tasks
- Saves in `.npz` format for TD3+BC offline training

### Pure RL Track (`research/pure_rl/`)

**On-policy RL: REPPO**
- Baseline: `RePPOAgent` from `models/rl/agents/reppo.py`
- Ideas: new algorithms, auxiliary tasks, reward shaping — written as idea specs in `research/pure_rl/ideas/`
- Training: `research/pure_rl/experiments/train_reppo.py`

**Offline RL: TD3+BC**
- `TD3BCAgent` trained on offline pick-and-place demonstrations
- Training: `research/pure_rl/experiments/train_td3_bc.py`
- Offline data generated by `scripts/generate_offline_data.py`

### EEG RL Track (`research/`)

**EEG Tokenizer** (`research/eeg/tokenizer.py`)
- Conv1D trunk: `(B, C, T_eeg)` → `(B, T_rl, token_dim)` — one token per RL timestep
- Trained end-to-end with RL loss

**Brain Conditioner** (`research/brain/`)
- Pluggable interface: `BrainConditioner` ABC
- Current idea: `TransformerDelta` — causal transformer on token history → delta_action + alpha gate
- Future idea: `DiffusionConditioned` (placeholder)
- New ideas: write spec in `research/ideas/`, implement, pass to `EEGRePPOAgent`

**EEG-Conditioned REPPO** (`research/agents/eeg_reppo.py`)
- `final_action = tanh(base_action + alpha * delta)`
- RL loss backpropagates through brain conditioner **and** EEG tokenizer (end-to-end)
- Insights from Pure RL track → transfer to EEG agent (e.g. better reward shaping, new algorithm)

### Simulation

- `scripts/simulate_mujoco.py` — visualise trained agent on any Gymnasium env
- `scripts/simulate_maniskill.py` — visualise trained agent on ManiSkill pick-and-place

### Layered Test Suite

Tests are layered — each layer verifies one component independently. Run them in order after any change:

| Layer | File | What it tests |
|-------|------|--------------|
| 1 | `test_01_tokenizer.py` | EEGTokenizer shapes and gradients |
| 2 | `test_02_brain.py` | BrainConditioner interface + TransformerDelta |
| 3 | `test_03_agent.py` | EEGRePPOAgent init, action, save/load |
| 4 | `test_04_envs.py` | Environment factory (all tracks) |
| 5 | `test_05_integration.py` | Full EEG rollout + gradient flow check |
| 6 | `test_06_pure_rl.py` | Pure RL agent (REPPO / TD3+BC) init and update |
| 7 | `test_07_rewards.py` | Reward sanity checks on MuJoCo and ManiSkill |

## Out of Scope

- **VLA track** (no language-model-based robot control in this repo)
- ROS 2 Gazebo (deferred until sim success)
- Real-time BCI streaming (inference uses pre-recorded EEG)
- Multi-task combined env (`Combined-v1`) — focus stays on individual pick-and-place tasks
- JAX / TensorFlow are allowed if an idea specifically needs them, but PyTorch is the default

---

## Design Constraints

- **GPU**: RTX 4070 (12 GB VRAM)
- **Framework**: PyTorch default; other frameworks allowed for specific ideas
- **Tasks**: `PickCube-v1`, `PushCube-v1`, `StackCube-v1`, `PullCube-v1` — do not change unless told
- **Modularity**: Swapping an RL algorithm or brain conditioner touches only `research/` files
- **Reproducibility**: All experiments configured via `ExperimentConfig` dataclass; logged to `output/`
- **No commits without approval**: Always explain changes and wait for confirmation before committing
